# Brand Assets

Coloca aquí los recursos de marca del negocio. Claude Code debe revisar esta carpeta antes de inventar colores, tipografías o usar logos placeholder.

Subcarpetas ya incluidas:
- `logos/` — logo en sus variantes (color, blanco, ícono/favicon)
- `photos/` — fotos reales del negocio, productos o equipo

Agrega también si aplican:
- `colors.md` — paleta de colores exacta en hex (primario, secundario, acentos, neutros)
- `fonts.md` — tipografías de marca, si ya existen

Si esta carpeta está vacía para un proyecto, Claude Code debe diseñar la identidad visual desde cero con buen criterio (apoyándose en las skills `frontend-design` y `ui-ux-pro-max`), no inventar que existe una marca ya definida.
